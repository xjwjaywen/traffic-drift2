# Manuscript versions

These are separate snapshots. Editing one directory does not overwrite the others.

| Directory | Purpose | Current PDF |
| --- | --- | --- |
| `pre_iot_20261019/` | Manuscript before the IoT-J reframing, copied from `traffic-drift2/Publication/jnca_submission_20261019/source/` | `main.pdf` (41 pages) |
| `iotj_minimal_20261103/` | Full IoT-J-oriented revision and source for the compact draft | `main.pdf` (19 pages) |
| `iotj_compact_20261107/` | Condensed teacher-review draft retaining the key TLS, QUIC, and 11-home IoT results | `main.pdf` (8 pages) |

The compact draft was derived from the full IoT revision. It is not a replacement for the pre-IoT manuscript. The pre-IoT PDF was copied byte-for-byte; the source and figures needed to continue editing it are also present.

Each IoT manuscript has its own S1 index. The compact S1 was rebuilt locally from the verified full-version archive with a compact-PDF hash and label map; its scientific payload is byte-identical. S2 and the server-generated S3 remain separate supplementary artifacts.
